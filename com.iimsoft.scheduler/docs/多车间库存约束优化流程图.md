```mermaid
flowchart TD
    %% 开始
    A[启动优化程序] --> B[读取 ERP/MES 数据]
    B --> B1[订单信息 (工艺路径, 批量)]
    B --> B2[车间产能数据]
    B --> B3[半成品安全库存要求]
    B --> B4[工艺顺序 & 加工时间]

    %% 初始化
    B1 --> C[初始化种群: 订单批次策略 + 车间内顺序]
    B2 --> C
    B3 --> C
    B4 --> C

    %% 迭代优化
    C --> D[开始优化迭代]
    D --> E[生成生产方案 (基因解码)]
    E --> F[调度仿真器]

    %% 仿真细节
    subgraph Simulation[调度仿真器]
        F --> F1[按工艺顺序依次安排车间生产]
        F1 --> F2[检查上游半成品库存是否 >= 安全库存]
        F2 -->|不足| F3[延迟下游任务 / 增加上游生产]
        F2 -->|满足| F4[执行该工序]
        F3 --> F4
        F4 --> F5[更新库存 (扣减/补充)]
        F5 --> F6[更新车间产能负载]
        F6 --> F7[记录任务完成时间]
    end
    
    %% 目标计算  
    F7 --> G[计算目标值]  
    G --> G1[总工期 Makespan]  
    G --> G2[总延误小时数]  
    G --> G3[库存波动指标]  
    G --> G4[总在制品 WIP]  
    G --> G5[车间负载平衡度]  
      
    %% 选择与进化  
    G1 --> H[非支配排序 + 拥挤度计算]  
    G2 --> H  
    G3 --> H  
    G4 --> H  
    G5 --> H  
  
    H --> I[选择 + 交叉 + 变异]  
    I --> D  
  
    %% 结束  
    D -->|达到迭代次数| J[得到 Pareto 前沿解]  
    J --> K[导出延误报表 & 库存变化曲线]  
    J --> L[可视化甘特图 & 库存动态图]  
    K --> M[结束]  
    L --> M
```
